# PhraseoLab

Интерактивный прототип занятия «Фразеологизмы. ЕГЭ — задание 25» на 45 минут: введение 2 мин, теория 10, практика 10, игра 18, финал 5.

## Разработка

Node.js 22+ и npm. Из корня репозитория:

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

React + TypeScript + Vite + Tailwind CSS v4 + GSAP/ScrollTrigger. Приложение статическое: сервер, API и секреты не нужны. `dist/` — результат сборки, пригодный для статического хостинга. Относительный Vite base позволяет разместить сайт и в подпапке.

## Что работает

Пять разделов, анимированная заставка, раскрывающиеся примеры, три задания с проверкой и объяснением, игра для трёх команд с 30 карточками и тремя уровнями. Команды ходят по очереди; правильный ответ приносит 1/2/3 подушечки, неверный — 0. Каждая карточка играется один раз, в том числе после ошибки. Сытость достигает 100% при 20 подушечках; очки продолжают начисляться. Игра завершается после всех 30 карточек. Сброс требует отдельного подтверждения. Итоги отражаются в финале. Состояние хранится в памяти и сбрасывается при перезагрузке страницы.

Вопросы игры временные, учебные: `src/data/content.ts`. Формат и номер задания необходимо сверять с актуальной демоверсией ФИПИ перед реальным занятием. Прототип не заявляет соответствие текущему официальному КИМ.

## Архитектура расширения

- `src/data/content.ts`: теория и редактируемый банк вопросов.
- `src/lib/game.ts`: чистая логика очков и ходов, покрытая тестами.
- `src/components/CharacterSlot.tsx`: заменяемый слот оригинального персонажа. Сейчас показаны условные CSS-макеты с подписью, внешние изображения не используются. Тип CharacterRole резервирует роли kitten/mother/dance для будущего рендера.
- `src/App.tsx`: разделы, практика и игра. Для 3D можно заменить CharacterSlot на canvas-компонент без изменения начисления очков. Голос, анимации мамы-кошки, скрытый режим учителя, сохранение сессий и финальный танец ещё не реализованы.
- Анимации GSAP очищаются при размонтировании и учитывают prefers-reduced-motion. Карточки теории используют нативные details, окно игры — dialog с Escape и клавиатурной навигацией.

## Публикация

Подключите GitHub-репозиторий к Vercel/Netlify/Cloudflare Pages: build `npm run build`, output `dist`, install `npm ci`, Node 22+. Либо загрузите содержимое `dist` на любой статический хостинг. Публикация исходников в GitHub сама по себе не публикует сайт.
